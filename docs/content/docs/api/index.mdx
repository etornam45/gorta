HTTP API documentation is in progress. Routes are mounted on your chosen prefix (typically `/auth`).

## Core routes

| Method | Path | Description |
| ------ | ---- | ----------- |
| `GET` | `/session` | Current session (if any) |
| `POST` | `/sign-out` | Revoke session and clear cookie |
| `GET` | `/me` | Authenticated user (requires session) |

Plugin routes (sign-up, sign-in, magic link, OAuth) are registered alongside these. See the [getting started](/docs) guide and plugin source under `plugins/` on GitHub.
